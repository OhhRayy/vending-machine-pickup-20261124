## What it does

`main.py` writes one pickup line to `/output/entry.txt`, spoken by a vending machine to a passing human. The program is deterministic (the same bytes on every run), uses no network, and needs no input.

The line (124 characters):

> Hey you — I've got cold drinks, warm snacks and exact change for a smile. Press B7 and let my coil drop you something sweet.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
